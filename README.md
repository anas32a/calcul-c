# calcul-c

Petit programme en C réalisé pour l’exercice 1 du TP Git et GitHub. Il demande deux entiers à l’utilisateur et affiche leur somme.

## Compilation

Depuis le dossier `calcul-c`, lance la commande suivante avec GCC.

```bash
gcc main.c -o calcul
```

## Exécution

```bash
./calcul
```

Par exemple, si tu saisis `4` et `7`, le programme affiche leur somme, `11`.
